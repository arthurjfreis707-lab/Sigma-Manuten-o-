# SIGMA 2.1 — Registro fotográfico
Atualização da versão 2.0 com campos para foto do antes e do depois em cada solicitação.
## Atualizar no GitHub
1. Extraia este ZIP.
2. No repositório, use Add file > Upload files.
3. Envie os arquivos desta pasta para a raiz, substituindo os arquivos existentes.
4. Clique em Commit changes.
5. Aguarde a atualização do GitHub Pages e recarregue o SIGMA no celular.
As fotos podem ser capturadas pela câmera ou escolhidas da galeria. São reduzidas automaticamente e guardadas localmente no navegador por solicitação.
Atenção: dados e fotos ficam no armazenamento local do navegador; não há sincronização entre dispositivos. O backup JSON da versão 2.0 não inclui as fotos.
